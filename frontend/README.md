# Frontend README

This is a minimal Expo app scaffold. To run:

1. Install dependencies

```bash
cd frontend
yarn
npx expo start
```

2. Open in Expo Go or a simulator. The app expects the backend at `EXPO_PUBLIC_BACKEND_URL` in the environment; default is `http://localhost:8000`.

To change the URL, set it in `frontend/.env` or your shell when running Metro.
